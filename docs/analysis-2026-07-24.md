# XSG (X Server Guard) — 设计分析文档

> 创建日期：2026-07-24
> XSG 是一个纯 Bash、零依赖的 VPS 一键安全加固脚本，单文件 979 行，5 Phase 覆盖从用户创建到运维设施的全链路。

---

## 一、XSG 各阶段功能盘点

### Phase 0: OS/网络检测

| 功能 | 说明 |
|------|------|
| **OS 检测** | 仅支持 Debian/Ubuntu，检测 systemd、apt |
| **网络连通性** | 测试 `8.8.8.8` 可达，DNS 解析验证 |
| **root 检查** | 必须 root 运行 |

### Phase 1: 管理员用户

| 功能 | 说明 |
|------|------|
| **用户创建** | 验证用户名合法性，检测冲突 (UID≥1000)，自动分配可用 UID |
| **SSH 密钥部署** | B+C 模式：是/否开关 → 粘贴已有密钥 或 生成新密钥对 (`ssh-keygen -t ed25519`) |
| **密码设置** | 交互输入，≥12 字符 或 ≥4 词口令短语 |
| **sudo 授权** | 是/否开关，强制密码认证 (`NOPASSWD` 禁用)，审计日志写入 `/var/log/sudo-audit.log` |
| **GitHub Deploy Key** | B+C 模式：是/否开关 → 粘贴已有 或 生成新 Ed25519 密钥对，存入 `~/.ssh/github_myx_local` |

### Phase 2: 安全基线

| 功能 | 说明 |
|------|------|
| **apt 更新** | `apt-get update && apt-get full-upgrade -y`，自动移除旧包 |
| **安全包安装** | ufw, fail2ban, aide, auditd, rkhunter, vnstat, unattended-upgrades |
| **禁用不必要服务** | cups, avahi-daemon, rpcbind, ModemManager, whoopsie |
| **/tmp /dev/shm noexec** | `fstab` 持久化挂载 |
| **core dump 禁用** | 三层防护：`limits.conf` (hard/soft 0) + `sysctl` (`kernel.core_pattern=|/bin/false`) + `systemd coredump.conf` |
| **文件系统模块黑名单** | cramfs, freevxfs, jffs2, hfs, hfsplus, squashfs, udf, usb-storage → `/etc/modprobe.d/xsg-blacklist.conf` |
| **网络协议黑名单** | dccp, sctp, rds, tipc → `/etc/modprobe.d/xsg-net-blacklist.conf` |
| **UFW 防火墙** | 默认 deny incoming + allow outgoing，SSH rate-limit，conntrack 双持久化 (iptables-save + before.rules) |
| **SSH 硬化** | 后量子 KEX (`sntrup761x25519-sha512`)，AEAD 密码 (`aes256-gcm`)，ETM MACs，死锁检测，自动回滚 (`sshd -t` + `.bak` 恢复) |
| **Fail2ban** | SSH jail (UFW ban action)，bantime=3600，findtime=600，maxretry=5 |
| **OOM 保护** | sshd `oom_score_adj=-1000` |

### Phase 3: 纵深防御

| 功能 | 说明 |
|------|------|
| **密码质量策略** | `pam_pwquality.so` minlen=12，`/etc/security/pwquality.conf` |
| **auditd** | 7 条规则：特权操作 (sethostname/setdomainname)、时间修改 (adjtimex/settimeofday/clock_settime)、文件系统挂载、cron 文件访问、SELinux/AppArmor 配置变更 |
| **SUID/SGID 清理** | 8 个二进制去特权位：wall, write, newgrp, chfn, chsh, mount, umount, su |
| **/proc hidepid** | `hidepid=2` 挂载 `/proc`，普通用户无法看到其他用户进程 |
| **rkhunter** | 安装 + 每周 cron 自动扫描，基线 `--propupd` |
| **cron/at 限制** | `/etc/cron.allow` 仅 root，`/etc/at.allow` 仅 root |

### Phase 4: 系统优化

| 功能 | 说明 |
|------|------|
| **sysctl 安全参数 (17 项)** | syncookies, rp_filter (0/1), ICMP redirect 禁用, source route 禁用, martian 日志, IP forwarding 禁用, IPv6 可选禁用 |
| **sysctl 性能参数 (20 项)** | BBR, TCP buffers (64MB rmem/wmem), fastopen, keepalive (60s), TIME_WAIT reuse, netdev backlog, somaxconn |
| **limits.conf** | nofile=1048576, nproc=65535, memlock=unlimited |
| **自动 swap** | btrfs 检测跳过，磁盘空间检查 (swap+2GB 余量)，`fstab` 持久化 |
| **NTP** | `systemd-timesyncd` 确保启用 |
| **DNS 加固** | 8.8.8.8 + 1.1.1.1 置顶，`chattr +i` 防 DHCP/cloud-init 覆盖，systemd-resolved fallback (symlink 场景) |

### Phase 5: 运维设施

| 功能 | 说明 |
|------|------|
| **unattended-upgrades** | 安全更新自动安装，每周清理 |
| **AIDE** | 文件完整性监控，每日 03:30 cron，仅报告 `Changed/Added/Removed` |
| **vnstat** | 网络流量统计 |
| **logrotate** | xsg 日志专用配置：weekly，rotate 4，compress，maxsize 20M |
| **内核重启检查** | 检测 `/var/run/reboot-required`，列出触发包 |
| **AES-256 加密备份** | `openssl enc -aes-256-cbc -pbkdf2` 加密关键配置目录，月检 03:00 cron，备份存 `/root/xsg-backups/` |
| **磁盘监控** | 每小时检查，阈值 90%，`df -h` 告警，可选 msmtp 邮件通知 |
| **ipset+geoip SSH 防御** | `xsg-blocked` ipset (hash:ip) + `xsg-throttle` (timeout 3600s)，国外失败的 IP 自动封禁，每 10 分钟 cron 扫描 `journalctl -u ssh`，systemd oneshot 开机恢复 |

## 二、竞品分析与借鉴

| 竞品 | 可借鉴技术 | 价值 |
|------|-----------|:--:|
| **du_setup** | SSH 自动回滚 (`sshd -t` 失败恢复) | ⭐⭐⭐ |
| **du_setup** | 配置修改前自动备份 (`.bak` + 时间戳) | ⭐⭐⭐ |
| **du_setup** | 幂等性设计 (重复运行不重复操作) | ⭐⭐ |
| **linux-ssh-init-sh** | 死锁检测 (禁止锁自己的场景检测) | ⭐⭐⭐ |
| **linux-ssh-init-sh** | 无头模式 (环境变量跳过交互) | ⭐⭐ |
| **hardening-ubuntu** | 预检清单 (安装前打印步骤) | ⭐⭐ |

### XSG 借鉴并实现的 3 项关键技术

1. **SSH 自动回滚** — 改 `sshd_config` 后 `sshd -t && systemctl reload sshd`，失败则 `cp .bak` 恢复
2. **死锁检测** — 未配 SSH key + 禁用密码 + 禁用 root → 拒绝执行
3. **配置备份** — `bak()` 函数，每个被修改的系统文件改前 `cp "$f" "$f.bak.$(date +%s)"`

```
XSG/
├── xsg.sh                    # 主脚本（单文件，bash，零依赖）
│
│   执行流程:
│   ┌─ Phase 0: OS/网络检测
│   ├─ Phase 1: 创建管理员用户（SSH key + GitHub Deploy Key + sudo + 密码）
│   ├─ Phase 2: 安全基线（UFW + SSH硬化 + Fail2ban + conntrack 持久化）
│   ├─ Phase 3: 纵深防御（noexec + core dump + 模块黑名单 + auditd + rkhunter）
│   ├─ Phase 4: 系统优化（BBR + sysctl + limits + swap + DNS + systemd-resolved）
│   └─ Phase 5: 运维设施（unattended-upgrades + AIDE + AES-256 备份 + 磁盘监控 + ipset 防御）
│
├── .githooks/                # pre-commit (shellcheck) + pre-push (shellcheck + shfmt)
├── README.md
├── LICENSE                   # MIT
└── docs/
    └── analysis-2026-07-24.md  # 本文档
```
